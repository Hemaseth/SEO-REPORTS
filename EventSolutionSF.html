Start Here — The Convergent Finding
● Flagged independently by all five analyses

Fix the brand’s identity & authority first

Anonymous "admin" authorship across all 16 posts plus an unsubstantiated “award-winning” claim is the #1 E-E-A-T fix, the #2 FLOW Optimize priority, a top-5 GEO change, and underlies the Win/Find trust gaps. A real operator — “Sheila” — demonstrably exists (testimonials, sheila@ email) but is credited nowhere. One body of work — a named, credentialed author with a bio and Person schema — lifts Content, E-E-A-T, GEO and AI-citation at once. Everything else is sequenced around it.

Critical & High Findings (Audit)
● High · Local / Schema / Conversion

Wrong phone number in structured data

Clickable tel: link & visible CTA415.816.5555
LocalBusiness schema telephone+1 (415) 816 5554 ✕

Schema feeds Google a number ending 5554; the real, displayed, click-to-call line ends 5555. A wrong number in the machine layer is a NAP-consistency defect and a directly lost booking. The standalone LocalBusiness block is also disconnected from the Yoast @graph (no @id) → two “Event Solutions” entities.

Fix — set telephone to verified +1-415-816-5555; add @id + merge into #organization. Verify the real number with the owner first.
● High · Trust

No privacy policy or terms — on a lead-capture site

All common privacy/terms URLs return 404 and there are no footer legal links, while the site runs contact forms collecting personal data. A direct Trustworthiness gap and compliance risk.

Fix — publish privacy policy + terms; link both in the footer.
● High · Social / On-Page

No og:image on homepage · Meeting Procurement has no meta description

The homepage declares twitter:card = summary_large_image but ships no og:image — every social/iMessage/Slack share is thumbnail-less (posts do have one). Separately, /meeting-procurement-hotel-site-selection/ has no meta description so Google fabricates the snippet.

Fix — branded 1200×630 default og:image + page heroes; write a 140–155-char description for Meeting Procurement.
