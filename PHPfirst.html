Start Here — The Convergent Finding
● Flagged independently by all six analyses

Fix the schema, the author identity, and the content depth — in that order

Three defects recur across every sub-audit. First: the FAQPage schema on every page is malformed — it is stored as an escaped JSON string inside a <script> block rather than valid JSON-LD. Google and all AI crawlers silently skip it, meaning 7+ service pages with FAQ sections earn zero FAQ rich result benefit. Second: author identity is anonymous — blog posts are attributed to the WordPress username "sheiladizon" rather than the co-founder Sheila Dizon-Burns, stripping the E-E-A-T value of every article and suppressing AI citation frequency. Third: service pages are 900–1,400 words against competitors (Acclime, InCorp Asia, Emerhub) who publish 3,000–5,000 word service guides that dominate the SERP. Fix the schema (hours, not days), humanize the authorship (one day), then expand content depth starting with the highest-revenue service pages — everything else sequences from these three.

● Critical · Schema / Entity Trust

US phone number (+1 415) on a Philippines-addressed LocalBusiness — entity trust failure

Google's local entity resolution uses telephone as a primary trust signal for the stated address. A +1 (415) San Francisco area code paired with a Bonifacio Global City, Philippines postal address degrades entity confidence and undermines Knowledge Panel eligibility. The LocalBusiness block also has no @id property — it cannot be linked to the Organization node in Block 1, so Google treats them as two separate, competing entities for the same business.

Fix — Add a Philippines +63 primary number to LocalBusiness telephone. Keep the US line as contactPoint with contactType: "customer service". Add "@id": "https://philippinehubpartners.com/#business" to the LocalBusiness block and merge both JSON-LD blocks into a single @graph (see Schema section for complete replacement code).

FAQPage schema is malformed — zero AI citation benefit

IssueImpact

Note on Google FAQ Rich Results: Google restricted FAQ rich results to government and healthcare sites in August 2023 — commercial B2B sites like PHP are no longer eligible for the accordion SERP feature. However, valid FAQPage schema does improve AI/LLM citation frequency and is used by ChatGPT, Perplexity, and Bing Copilot to extract structured Q&A content. The malformed output means PHP earns none of this benefit. Fix for AI citation value, not for Google rich results.

Fix — In Rank Math, diagnose and fix the FAQPage output mode — it should emit a valid JSON-LD object, not an escaped string. Validate via search.google.com/test/rich-results. Once fixed, the existing FAQ HTML on 7 service pages will be machine-readable for AI crawlers.
● Critical · GEO / AI Visibility

No llms.txt — AI search systems must guess your content priority

Neither /llms.txt nor /llms-full.txt exists. With 19 blog posts and 15 pages, the site has meaningful citable content but AI crawlers have no map for prioritizing it. Competitors who add llms.txt first gain a durable AI-citation advantage in a category where authoritative firm selection (Acclime, InCorp, Emerhub) is actively surfaced by ChatGPT and Perplexity to users asking "best Philippines company formation consultants."

Fix — Create /llms.txt listing: company description (3 sentences), key service pages with one-line descriptions, top 5 most-cited blog articles. Create /llms-full.txt with full text of the 5 most authoritative articles. Total effort: 2–3 hours.

● High · E-E-A-T / AI Citation

Author identity is anonymous — "sheiladizon" credits a WordPress username, not a person

All blog posts are attributed to the username sheiladizon. The real author is Sheila Dizon-Burns, co-founder with demonstrable business credentials. The firm also has a second co-founder, Atty. Marvi R. Abo, with attorney credentials — a significant E-E-A-T signal going completely unused in author schema. Anonymous authorship is penalized in Google's post-Dec 2025 E-E-A-T guidelines and suppresses AI citation (AI systems strongly prefer attributable named-entity sources).

Fix — Create author bio pages for Sheila Dizon-Burns and Atty. Marvi R. Abo. Include: full name, title, credentials, LinkedIn URL, 100–150 word bio. Add Person schema with sameAs to LinkedIn profiles and knowsAbout arrays. Update all blog post bylines to link to author pages.
● High · On-Page / Template Bug

Duplicate H1 tags on Blog/Insights and IT Setup pages — template bleed-in

The Blog/Insights page (/new-insight/) and IT Setup page (/services/it-set-up/) both carry two H1 tags. The second H1 on both pages is the homepage hero headline ("Your Gateway to the Philippine Market…") injected by the global page builder template. Google parses both as equal H1 declarations and cannot determine heading hierarchy for either page.

Fix — In WordPress page builder (Betheme/BeBuilder), set a unique page template for the Blog index and IT Setup page that suppresses the global hero section. This is a template override, not a content edit — takes under 30 minutes per page.
