How to use this document

Fix in dependency order, verify each step

This walkthrough is the implementation companion to the audit. The audit says what is wrong and why; this says how to fix it. Work top-down — earlier fixes unblock later ones.

Critical 01 · Solution

Fix the broken homepage service navigation

Critical · Technical / Link graph · Effort: Low

Repoint the service cards and retire the dead /services-details/ route

Every homepage service card links to /services-details/, a leftover Crafto demo URL that 404s (16 links). Equity and clicks leak into a dead page.

Steps

  1. In WordPress, open the homepage in Elementor and select each service card / image-link in the services grid.
  2. In each card's Link field, replace https://velvetvisibilitylabs.com/services-details/ with the matching real service URL — e.g. the "SEO audit" card → /home/seo-audit/, "Technical SEO" → /home/technical-seo/, and so on for all five services. Map by the card's label/icon.
  3. Repeat for any duplicate references (the audit found 16 instances; check the footer and any "read more" buttons too).
  4. Add a safety 301 so the dead URL never returns a 404 again. In Yoast → Redirects (or your redirect plugin), add: /services-details/ → /services/ (301).
  5. Re-crawl the homepage (Screaming Frog, or re-run the link check) to confirm zero internal links resolve to /services-details/.
Verify — curl -sS -o /dev/null -w "%{http_code}" https://velvetvisibilitylabs.com/services-details/ returns 301, and every homepage service card opens its real page. No card should land on a 404.
Critical 02 · Solution

Add a meta description to all 10 pages

Critical · On-Page · Effort: Low

Configure Yoast and write one description per page

No page emits a meta name="description". Yoast is installed but the description fields are empty, so Google writes the snippet for you.

Steps

  1. Edit each page → scroll to the Yoast SEO box → Meta description field.
  2. Write a unique 140–155 character description per page: lead with the page's intent, include the primary keyword naturally, end with a reason to click. Keep the green length bar.
  3. Optionally set a site-wide default template under Yoast → Settings → Content types, but per-page hand-written descriptions outperform templates — do those for the 10 pages.
  4. Confirm Yoast's snippet preview shows your text, not auto-generated content.

Critical 03 · Solution

Deploy the entity schema graph

Critical · Schema / GEO · Effort: Medium

Add Organization, Service, and FAQPage JSON-LD

The site ships only Yoast defaults — no Organization, Service, or FAQPage. An AEO agency must give answer engines a structured entity to resolve and cite. Add the blocks below (replace VERIFY: placeholders with confirmed values).

1 · Organization (site-wide — add via Yoast → Schema, or a header snippet)

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Organization",
  "@id": "https://velvetvisibilitylabs.com/#org",
  "name": "Velvet Visibility Labs",
  "url": "https://velvetvisibilitylabs.com/",
  "logo": "https://velvetvisibilitylabs.com/wp-content/uploads/VERIFY-logo.webp",
  "description": "SEO and Answer Engine Optimization agency serving India, Vietnam and the US.",
  "areaServed": ["IN","VN","US"],
  "email": "info@velvetvisibilitylabs.com",
  "sameAs": [
    "https://www.linkedin.com/company/VERIFY-handle"
    /* add Clutch, GoodFirms, DesignRush URLs here once profiles exist (C05) */
  ]
}
</script>

2 · Service (one per service page — example for the AEO page)

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Service",
  "serviceType": "Answer Engine Optimization",
  "provider": { "@id": "https://velvetvisibilitylabs.com/#org" },
  "areaServed": ["IN","VN","US"],
  "name": "Answer Engine Optimization (AEO)",
  "description": "Optimization to get your brand cited by ChatGPT, Perplexity and Google AI Overviews.",
  "url": "https://velvetvisibilitylabs.com/aeo-ai-search/"
}
</script>

3 · FAQPage (on each money page — match real PAA questions)

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    { "@type": "Question", "name": "What is Answer Engine Optimization?",
      "acceptedAnswer": { "@type": "Answer",
        "text": "AEO is the practice of structuring content and entity signals so AI answer engines (ChatGPT, Perplexity, Google AI Overviews) cite your brand in their responses." } },
    { "@type": "Question", "name": "How is AEO different from SEO?",
      "acceptedAnswer": { "@type": "Answer",
        "text": "SEO targets ranked links on a results page; AEO targets being quoted inside an AI-generated answer. They overlap but need different signals." } }
  ]
}
</script>

Steps

  1. Add the Organization block once, site-wide (Yoast's schema settings can emit much of this — fill Organization name, logo, and social profiles under Yoast → Settings → Site basics / Site representation).
  2. Add a Service block to each of the six service pages, changing serviceType, name, description, and url.
  3. Add a FAQPage block to each money page using real questions the page visibly answers (don't mark up FAQs that aren't on the page — Google requires visible matching content).
  4. Cross-link everything by @id (Service provider → the Organization @id).
  5. Hold the AggregateRating/Review block until reviews are verified (see C05/H03).
Verify — paste each URL into the Google Rich Results Test and Schema.org validator; confirm Organization, Service, and FAQPage are detected with no errors.
Critical 04 · Solution

Un-orphan the flagship AEO page

Critical · Link graph · Effort: Low

Route in-content internal links into /aeo-ai-search/

The AEO page — the brand's differentiator — has zero in-content internal links and is reachable only from the top nav.

  1. Add a prominent in-content link to /aeo-ai-search/ from the homepage body (e.g. a "Cited by AI? See our AEO service" link in the AI section, not just the menu).
  2. Link to it from the /services/ hub as a first-class service.
  3. Add a contextual link from each related service page (technical, on-page) — e.g. "pairs with our Answer Engine Optimization work".

Critical 05 · Solution

Establish the brand as an external entity

Critical · GEO / Off-site · Effort: Medium · the keystone

Get listed, get reviewed, get cited

The brand exists in no external index — no directory, no reviews platform, no AI-citation footprint. AI engines cannot cite a brand with no external signals. This is the single highest-leverage workstream.

  1. Claim a Clutch.co profile (clutch.co/get-listed — free). Complete every field: services, focus areas, geographies, logo, description.
  2. Collect 3 verified reviews from the named homepage clients (confirm consent first). Clutch's phone-verified reviews are the most trusted B2B corroboration signal and the prerequisite for roundup inclusion.
  3. Create GoodFirms, DesignRush, and Sortlist profiles in parallel — these become entity anchors for AI-citation engines.
  4. Add every profile URL to the Organization sameAs array (C03) so search engines connect the entity to its off-site presence.
  5. Once reviews exist, pitch the AEO roundups that currently list no Asia-Pacific agencies (the FLOW supporting document names the specific targets and angles).
  6. Seed a LinkedIn cadence and participate in r/SEO / r/bigseo — Perplexity cites Reddit heavily.
Verify — searching the brand name returns a Clutch/GoodFirms result; the homepage star claim links to a real profile; re-running the AI-citation baseline shows the brand resolving as an entity.
● Gate

Do not publish AggregateRating schema or surface the "4.8 stars" claim as a ranking signal until the reviews exist on a real platform and the owner confirms them.

Critical 06 · Solution

Bring mobile LCP into range

Critical · Performance · Effort: Medium

Cut image weight, fix the LCP element, cache at the edge

Mobile LCP is 7–11s on every page (Poor). Root causes: 1 MB+ PNG hero images as the LCP element, theme payload, and no edge full-page cache.

  1. Convert content images to WebP/AVIF. Install ShortPixel or Imagify, bulk-optimise the media library, and enable automatic next-gen delivery. The five 1 MB+ PNGs (ChatGPT-generated heroes, SEO-Audit.png, technical-seo.png) are the priority.
  2. Right-size the LCP image. Identify the homepage hero (the LCP element at 11s), export it at the actual displayed dimensions, and serve responsive srcset sizes. Add fetchpriority="high" to the hero and lazy-load everything below the fold.
  3. Enable edge caching. The homepage shows cf-cache-status: DYNAMIC — add a Cloudflare cache rule (or APO for WordPress) to full-page-cache HTML for anonymous visitors.
  4. Trim render-blocking payload. Use a caching/optimisation plugin (WP Rocket / LiteSpeed) to defer non-critical CSS/JS from Crafto + Elementor and inline critical CSS.
  5. Remove the 94 unused Crafto demo images from the media library to cut page weight and clutter.
Verify — re-run PageSpeed Insights (mobile): target LCP < 2.5s and page weight under ~1 MB. Watch for the first CrUX field dataset as traffic grows.

High 02 · Content · Effort: Medium

Expand and differentiate the thin service pages

Five service pages run ~350 words at 48–53% uniqueness; the AEO page is 281 words. Competitors run 1,800–5,100 words with real structure.

Per-page blueprint (apply to each money page)

  • Target 1,000–1,800 words with a real H2 layer: What it is → Why it matters in 2026 → How we do it (process) → What you get / deliverables → Results / proof → FAQ.
  • Make each service page's "How we do it" genuinely different — replace the shared scaffold so uniqueness rises well above 50%.
  • Add a 130–170-word extractable answer block near the top (the passage an AI engine can lift).
  • Rebuild /aeo-ai-search/ first to the depth of the pattern-match competitor (Victorious): what AEO is, which platforms you optimise for (ChatGPT, Perplexity, AI Overviews), process, and at least one quantified result.
Verify — re-run the uniqueness pass; pairwise Jaccard across the service cluster drops and each page clears ~1,000 words with a visible FAQ.
High 03 · Trust · Effort: Medium · owner-gated

Make the trust claims verifiable

"4.8 stars / 3 continents", "19.58% profit", and named testimonials have no schema and no external platform behind them.

  1. Confirm with the owner which reviews/testimonials are real and have consent to publish.
  2. Drive those reviews onto a real platform (Clutch / Google) — see C05.
  3. Once live, link the homepage star claim to that platform and add AggregateRating schema referencing the verified count and value.
  4. Re-state or remove any stat (e.g. "19.58% profit by sales") that can't be sourced.

  2. Replace the 94 Crafto demo-* placeholder graphics with real brand imagery (or remove the sections that only exist to show demo art).

High 05 · On-Page · Effort: Low-Medium

Add an H2 section layer to every money page

Money pages jump H1 → H3 with zero H2s — no semantic structure for crawlers or AI extraction.

  1. In Elementor, set each major section heading to H2 (Heading widget → HTML Tag → H2), reserving H3 for sub-points.
  2. Use the blueprint from H02 as the H2 outline (What it is / Why / Process / Deliverables / Results / FAQ).
  3. Keep exactly one H1 per page (the page title).
Verify — curl -s <url> | grep -c '<h2' returns 4+ on each money page.
High 06 · SXO · Effort: Medium

Match the channel to the SERP

Three of four money keywords are won by listicles/directories, not service pages.

  • For "AEO agency" / "answer engine optimization services" / "technical SEO services": pursue directory + roundup inclusion (C05) rather than trying to rank a thin service page on the head term.
  • Prioritise "SEO audit service" organically — it's the one keyword where agency service pages win (8/10), and you own /home/seo-audit/. Bring it to parity (schema + depth) first.
  • Target long-tail variants ("technical SEO for [industry]", "AEO for India B2B") where a service page can compete.
Verify — brand appears in at least one roundup/directory within the quarter; /home/seo-audit/ begins ranking for its long-tail variants.

High 08 · Technical hygiene · Effort: Low

Add security headers and suppress the version banner

No HSTS / X-Frame-Options / X-Content-Type-Options / Referrer-Policy; X-Powered-By: PHP/8.3.30 exposed.

# Cloudflare → Rules → Transform Rules → Modify Response Header (add):
Strict-Transport-Security: max-age=31536000; includeSubDomains
X-Frame-Options: SAMEORIGIN
X-Content-Type-Options: nosniff
Referrer-Policy: strict-origin-when-cross-origin

# Remove the stack banner (PHP / server config):
header_remove('X-Powered-By');   // or expose_php = Off in php.ini
  1. Add the four response headers via Cloudflare Transform Rules (or .htaccess / server config).
  2. Disable expose_php (or strip X-Powered-By) so the PHP version is no longer advertised.
  3. Tighten the CSP beyond upgrade-insecure-requests once you've inventoried allowed sources.
Verify — curl -sI https://velvetvisibilitylabs.com/ shows the four headers and no X-Powered-By; securityheaders.com grade improves to A/B.
Medium Findings · Solutions (short)

Cleanup tier

Medium 01 · URL architecture

Flatten the /home/ service nesting

Service pages sit under a redirecting /home/ parent. Either move them to clean /services/<slug>/ URLs with 301s from the old paths, or — if the effort/redirect risk isn't worth it on a 10-page site — leave them and simply remove the redirecting /home/ parent from any menus. Decide deliberately rather than leaving the demo artifact. If you migrate, 301 every old URL and update internal links + the sitemap.

Medium 02 · Redirects

Collapse the www-over-HTTP double hop

# Cloudflare → Rules → Redirect Rules (single hop to canonical apex):
# If hostname starts with "www"  →  301  https://velvetvisibilitylabs.com/$path
# Ensure the rule fires for both http and https on www in one step.

Today http://www… takes two 301s to reach the apex host; one redirect rule sends www straight to the canonical apex over HTTPS.

Medium 03 · Open Graph

Add social-share images to the money pages

Set a 1200×630 og:image on /aeo-ai-search/ and /services/ (and replace the homepage demo placeholder) via Yoast → Social, or per-page Yoast "Social image". Use a branded graphic, not the Crafto demo asset.
