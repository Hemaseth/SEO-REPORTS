Executive Summary

The one-page picture

For a 90-second read before the meeting.

What's working

  • All major search and AI crawlers (Googlebot, Bingbot, GPTBot, ClaudeBot, PerplexityBot, OAI-SearchBot) return 200 — nothing is blocked.
  • HTTPS is enforced and apex/www normalise correctly to one canonical host; self-canonicals are correct on all 10 pages.
  • Image alt coverage is complete on the audited pages — zero missing and zero empty alt attributes.
  • The brand positioning is sharp and timely: "Found on Google. Cited by AI." is exactly the right wedge for 2026, and the AEO focus is a genuine differentiator if the proof is built.

What's holding the site back

  • The homepage's main service navigation is broken — every service card links to a page that returns 404.
  • No page on the site has a meta description, and no page ships entity schema (Organization / Service / FAQ) — striking for an agency that sells answer-engine optimization.
  • The brand does not exist in any external index — no directory listing, no reviews platform, no AI-citation footprint. The domain is five weeks old.
  • Mobile Largest Contentful Paint is 7–11 seconds on every page measured — firmly in Google's "Poor" band.

If you do five things this week

  1. Repoint the homepage service cards to the real service URLs and retire the dead /services-details/ route.
  2. Fix the broken email link on the contact path (it currently points to an unreachable web address, not an email address).
  3. Add a unique meta description to all 10 pages via the existing Yoast install.
  4. Replace the placeholder social-share image (currently a leftover theme-demo graphic).
  5. Begin entity establishment — claiming the directory and reviews profiles that every competitor already holds is the keystone, and it is part of the engagement scope to execute.

Start Here — The Convergent Finding

It looks finished. Structurally, it is still launch day.

● The convergent finding

Velvet Visibility Labs presents as an established agency but is, underneath, a five-week-old Crafto theme demo that was published before its foundation was built.

That reframes the work: this is a launch checklist, executed in order, not a turnaround. Deep Dive · Technical SEO

Clean plumbing, broken wiring

The fundamentals are sound: HTTPS is enforced, apex and www normalise to a single canonical host, self-canonicals are correct on all 10 pages, robots.txt allows crawling and declares the sitemap, and the Yoast sitemap index is valid. The www-over-HTTP path takes two hops to reach the canonical host — minor. Where it breaks is internal wiring: the /services-details/ 404 hub (Critical 01), the orphaned flagship (Critical 04), a malformed email link (High 01), and the Cloudflare email-protection endpoint that 404s for non-JS agents. Security headers are largely absent and the PHP version is exposed (High 08). The service pages are also nested under a /home/ parent that itself redirects to the root — an Elementor/Crafto artifact that buries services a level deeper than the flat /services/ hub implies. Full evidence is in the technical surface finisher and link-graph supporting documents; the remediation sequence is part of the engagement scope.

TTFB sits at 590–980 ms, so the server is not the bottleneck — render and image weight are. The likely LCP element is an unoptimised 1 MB+ PNG hero; page weight runs 0.9–1.9 MB. No CrUX field dataset exists yet, so these are lab figures, but the gap to "Good" is large enough that the direction is unambiguous. Image alt hygiene is the bright spot (complete coverage), which keeps the Images lens at 75 despite the weight problem. The optimisation plan is part of the engagement scope.

Limits of this audit

What this audit can and cannot say

Measured, not estimated

Every score traces to evidence captured directly from the live site, live SERPs, or the PageSpeed Insights API. Where a surface could not be measured, it is flagged here rather than estimated.

Field performance data

No CrUX field dataset exists for any URL — expected for a five-week-old domain with low traffic. Performance is scored from PageSpeed Insights lab data (mobile). Field data should be re-checked as traffic grows.

Backlinks

The free Common Crawl endpoint timed out on attempt; paid backlink data (Ahrefs / Moz / DataForSEO) was not available. Given the domain's age a near-zero referring-domain count is expected, but it is unconfirmed.

Business-internal surfaces

Google Business Profile internals, Search Console impressions/positions, and GA4 conversions require owner-authenticated access not provided for this pass. They are flagged in the Measurement Plan.
